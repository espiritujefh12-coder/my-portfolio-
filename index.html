CC102 Final Project

Smart Student Helper

A Java programming project designed to help students perform simple tasks such as multiplication tables, palindrome checking, date and age information, diamond patterns, and SDG awareness.

Java Code Sample

public class SmartStudentHelper {
    public static void main(String[] args) {
        System.out.println("SMART STUDENT HELPER");
        System.out.println("Welcome, Student!");
        System.out.println("1. Multiplication Table");
        System.out.println("2. Palindrome Checker");
        System.out.println("3. Date and Age");
        System.out.println("4. Diamond Pattern");
        System.out.println("5. SDG Awareness");
        System.out.println("6. Exit");
    }
}
